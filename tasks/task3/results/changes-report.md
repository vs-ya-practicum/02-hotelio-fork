# Задание 3 — Отчёт о внесённых изменениях

## Расположение реализации

Полная запускаемая реализация находится в [реализации задания 3](../../../_implementation/task3/README.md).

Эта директория содержит отчёт, а не дублирующую копию исходного кода. Директория с реализацией находится в том же репозитории и содержит Docker-конфигурацию, исходный код, тесты и инструкции по запуску.

## Внесённые изменения

- `booking-subgraph` возвращает бронирования по `userId`, реализует ACL через заголовок запроса `userid` и предоставляет федеративную ссылку на `Hotel`.
- `hotel-subgraph` возвращает описания отелей, разрешает сущности `Hotel` по ID и использует пакетную загрузку и кеширование DataLoader в рамках одного запроса, чтобы исключить N+1-запросы.
- `promocode-subgraph` отвечает за проверку промокодов и переопределённую скидку бронирования. `DiscountInfo.originalDiscount` передаётся внутри федерации на основе базовой скидки бронирования.
- `apollo-gateway` объединяет сабграфы бронирований, отелей и промокодов, передаёт заголовок запроса `userid` и предоставляет единый API по адресу `http://localhost:4000/`.
- `.delivery/task3.compose.yml` запускает полный Docker-стек из четырёх сервисов.
- Foundation- и end-to-end-тесты Vitest проверяют отдельные сабграфы и федеративный сценарий через Gateway.
